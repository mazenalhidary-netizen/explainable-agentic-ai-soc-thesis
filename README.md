\# An Explainable Agentic AI Framework for Security Operations Centers



\*\*Enhancing Threat Detection, Incident Response, and Analyst Trust\*\*



A Master's research proposal in Cybersecurity, Faculty of Computer and Information Technology, Department of Cybersecurity, Sana'a University.



\---



\## 📖 About



This repository contains the LaTeX source and documentation for a research proposal on an \*\*Explainable Agentic AI Framework\*\* that integrates autonomous AI agents with Explainable AI (XAI) mechanisms to enhance Security Operations Centers (SOCs).



\### Research Objectives

\- Design and implement an Explainable Agentic AI Framework for SOCs

\- Improve threat detection accuracy

\- Reduce MTTD / MTTR

\- Increase analyst trust via transparent, human-understandable explanations



\### Keywords

Agentic AI · Explainable AI (XAI) · Security Operations Center (SOC) · Threat Detection · Incident Response · Analyst Trust · SHAP · MTTD · MTTR
